# @lahjiobn Instagram (Bangla account): launch kit + week 1

All images are in `out/instagram/bangla/` (re-render with `node scripts/render-insta.mjs`; code in `src/insta/`).
Feed posts are 1080 × 1350 (4:5). `03-grid-preview/` shows how the profile will look. Don't post the preview images.

## Step 0 · Set up the profile (5 minutes)
- **Profile picture:** `00-profile/profile-picture.png`
- **Name field** (searchable): `Lahjio | সৌদি আরবি শেখো`
- **Category:** Education
- **Bio:**
  ```
  🇸🇦 সৌদি আরবি শেখো, বাংলায়
  🎧 অডিওসহ ৭৭৩+ শব্দ · দিনে ৫ মিনিট
  🆓 ফ্রি শুরু করো 👇
  ```
- **Link:** `https://lahjio.com`
- **Story highlights:** post each cover as a story, then add it to a highlight with this name:
  `highlight-1-start` → **শুরু** · `highlight-2-phrases` → **বাক্য** · `highlight-3-quiz` → **কুইজ** · `highlight-4-tips` → **টিপস** · `highlight-5-app` → **অ্যাপ**
