# @lahjioapp Instagram (English account): launch kit + week 1

All images are in `out/instagram/english/` (re-render with `node scripts/render-insta.mjs english`; code in `src/insta/`).
They are the same designs as the Bangla account (@lahjiobn), with English text and the @lahjioapp handle.
Feed posts are 1080 × 1350 (4:5). `03-grid-preview/` shows how the profile will look. Don't post the preview images.

## Step 0 · Set up the profile
- **Profile picture:** `00-profile/profile-picture.png`
- **Name field** (searchable): `Lahjio | Learn Saudi Arabic`
- **Category:** Education
- **Bio:**

  ```
  🇸🇦 Learn real spoken Saudi Arabic
  🎧 773+ words with native audio · 5 min a day
  🆓 Start free 👇
  ```
- **Link:** `https://lahjio.com`

  `highlight-1-start` → **Start** · `highlight-2-phrases` → **Phrases** · `highlight-3-quiz` → **Quiz** · `highlight-4-tips` → **Tips** · `highlight-5-app` → **App**
